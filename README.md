# IFCE Living Book — أكاديمية أساسيات التأمين التفاعلية

كتاب تعليمي حي ثلاثي الأبعاد لمنهج أساسيات التأمين (IFCE)، يجمع بين:

1. **كتاب ثلاثي الأبعاد** (CSS 3D): صفحتان متقابلتان RTL، تقليب حقيقي للورق، سحب وأسهم ولوحة مفاتيح، صوت تقليب مُولَّد مع زر كتم، فتح الغلاف ومؤثر افتتاح الفصل، عناصر «تنبثق» من الورق.
2. **منصة تعليم متدرجة**: لكل درس أهداف، تعريف، شرح شامل + «اشرح لي ببساطة» + «تعمّق أكثر»، مصطلحات إنجليزية، أمثلة بسيطة/متوسطة/متقدمة، مقارنة، أخطاء شائعة، ملخص تفاعلي.
3. **محرك اختبارات وإتقان**: اختباران منفصلان لكل درس (شامل + سيناريوهات)، وضعا «التعلم» و«التقييم»، حد إتقان 90% قابل للتعديل، قفل الدروس حتى الإتقان وتأكيد الانتقال، مراجعة ذكية للمفاهيم الضعيفة، سجل أخطاء، بطاقات مراجعة، ومحاكاة امتحان مؤقتة.

> محتوى أصلي تدريبي غير رسمي. لا ينسخ نصوص الكتاب الرسمي أو أسئلته. الحقوق المحفوظة: https://t.me/B1Ver

## التشغيل

```bash
npm install
npm run dev              # خادم التطوير
npm test                 # 423 اختبارًا آليًا
npm run build            # نسخة متعددة الملفات في dist/ مع Service Worker للعمل دون إنترنت
npm run build:standalone # ملف HTML واحد مستقل في dist-standalone/index.html يعمل بفتحه مباشرة (file://)
npm run preview          # معاينة نسخة dist/
```

- لا يعتمد على أي API خارجي أو خدمة ذكاء اصطناعي. الخطوط العربية مضمّنة محليًا (IBM Plex Sans Arabic + Noto Naskh Arabic).
- التقدم يُحفظ في `localStorage` (المفتاح `ifce-living-book:v1`) مع تصدير/استيراد JSON من صفحة الإعدادات.
- التوجيه عبر `#/…` فيعمل من أي استضافة ثابتة ومن `file://`.

## البنية المعمارية

```
src/
  app/            الموجه (hash router)، مخزن الحالة (Context + reducer + حفظ تلقائي)، الصوت، الهيكل العام
  engine/         منطق نقي قابل للاختبار
    calc.ts         حسابات التأمين: تحويل الخطر، التجميع، التأمين الذاتي، المشاركة، إعادة التأمين،
                    التعويض، النسبية، المشاركة في التعويض (طريقتان)، الحلول
    progress.ts     الإتقان، القفل، الأخطاء، المفاهيم الضعيفة، الحفظ/الاستيراد/التصدير
    quiz.ts         خلط الأسئلة والخيارات، التصحيح، بناء الامتحان حسب التوزيع دون حشو
    random.ts       مولد عشوائي حتمي (بذور) للمحاكاة والخلط
  content/        المحتوى التعليمي منفصل تمامًا عن الواجهة
    chapters/structure.ts   هيكل الفصول الـ11 ودروسها (59 درسًا)
    chapters/*.ts           الدروس المؤلفة
    questions/*.ts          بنوك الأسئلة (الإجابة الصحيحة تُكتب أولًا وتُخلط عند العرض)
    concepts.ts             تسميات عربية لوسوم المفاهيم
    reviewLog.ts            سجل المراجعة العلمية
  components/
    book/Book3D.tsx         محرك الكتاب (صفحتان على الشاشات الكبيرة، صفحة واحدة ≤980px)
    book/LessonPages.tsx    صفحات الدرس (يمين: الشرح، يسار: التجربة/المخطط)
    quiz/QuizRunner.tsx     مشغل الاختبارات والامتحان والنتائج
    ui/                     مكونات مشتركة
  labs/           24 مختبرًا: LabShell يوحد (الهدف، المتغيرات، «توقّع ثم اكشف»، أدوات تحكم، نتائج لحظية،
                  تفسير، خطأ شائع وتصحيحه، إعادة التجربة)
  pages/          الرئيسية، المكتبة، الكتاب، المختبرات، مركز الاختبارات، الامتحان، الإتقان، المراجعة،
                  الإعدادات، سجل المراجعة العلمية
  styles/         رموز التصميم (فاتح/داكن)، الكتاب ثلاثي الأبعاد، المكونات
tests/            حسابات، سلامة بنك الأسئلة، الإتقان والحفظ، الامتحان، الواجهة والتنقل
```

### ترتيب صفحات الدرس في الكتاب

| الانتشار | الصفحة اليمنى (الشرح) | الصفحة اليسرى (التفاعل) |
|---|---|---|
| 1 | الأهداف والتعريف (+ لافتة افتتاح الفصل) | بطاقات المصطلحات ثلاثية الأبعاد ومسار الدرس |
| 2 | الشرح + «اشرح لي ببساطة» / «تعمّق أكثر» | المختبر التفاعلي |
| 3 | أمثلة متدرجة بخطوات تُكشف تباعًا | مقارنة المفاهيم + تحقق سريع |
| 4 | الأخطاء الشائعة (اكشف التصحيح) | ملخص بطاقات تفاعلية |
| 5 | التقييم: الاختباران | لوحة إتقان الدرس وبوابة الانتقال |

| 11 عملية التأمين في المملكة | هيكل فقط |

- الإجمالي: **31 درسًا قابلًا للدراسة** من 59 (29 مكتملة + 2 بحاجة لمراجعة)، **355 سؤالًا أصليًا** (222 شاملًا + 133 سيناريو)، **24 مختبرًا**.
- «مكتمل» هنا يعني: مؤلف أصليًا وخضع لتحقق داخلي آلي (مفاتيح الإجابات، الحسابات، الاتساق، غياب تلميح طول الإجابة). **لم يخضع بعد لمراجعة خبير بشري** مقابل نص الإصدار الرابع — انظر صفحة «سجل المراجعة العلمية» داخل التطبيق.
- الدروس «قيد الإعداد» لا تُعرض كدروس جاهزة، والدروس «تحتاج مراجعة» تظهر بتنبيه ولا تدخل بنك الامتحان ولا سلسلة القفل.

### محاكاة الامتحان
التوزيع المعتمد (100 سؤال / ساعتان): الخطر 18، السوق 10، المبادئ القانونية 36، التنظيم 12، الأخلاقيات 2، الإجراءات 10، المنتجات وخدمة العملاء 12.
البنك الحالي يغطي الخطر والسوق والمبادئ القانونية فقط، لذلك **المحاكاة الكاملة غير متاحة بعد**؛ التطبيق يعرض النقص بوضوح ويتيح محاكاة جزئية من 64 سؤالًا بزمن متناسب (72 ثانية/سؤال) — ولا يحشو العدد بأسئلة مكررة أو غير مراجعة.

## ما يحتاج مراجعة بشرية
- مطابقة كل الدروس مع نطاق ومصطلحات الإصدار الرابع (لم يكن نص المنهج متاحًا أثناء التطوير).
- عدد أسئلة الامتحان وأوزانه (مأخوذة من متطلبات المشروع؛ مدة 120 دقيقة مؤكدة جزئيًا من الأكاديمية المالية).
- الإطار النظامي السعودي: هيئة التأمين وانتقال الإشراف، الأنظمة السارية، لجان المنازعات (تحقق جزئي من مصادر ثانوية).
- قواعد السبب المباشر مع الأخطار المستثناة، توقيت المصلحة التأمينية، ترتيب توزيع الاسترداد في الحلول، أحكام العقد والإفصاح محليًا.

## الجودة والاختبارات
- `tests/calc.test.ts` — كل الحسابات بقيم معروفة.
- `tests/content/questions.test.ts` — كل سؤال: 4 خيارات فريدة، مفتاح صالح، تعليل لكل خيار، الدرس موجود، وسم مفهوم مُعرّف، **وعدم كون الإجابة الصحيحة أطول بوضوح في أسئلة السيناريو**؛ وكل درس مكتمل فيه كامل العناصر التعليمية ومختبر موجود.
- `tests/progress.test.ts` — الإتقان والقفل والتأكيد ووضع المعلم والأخطاء والحفظ/الاستيراد.
- `tests/quiz.test.ts` — الخلط، التصحيح، بناء الامتحان دون تكرار، الإبلاغ عن النقص، المراجعة الذكية.
- `tests/ui.test.tsx` — التنقل وتقليب الصفحات بالأزرار ولوحة المفاتيح (RTL)، طبقات الشرح، قفل الدروس، أدوات المختبرات، تدفق الاختبار وحفظه.
- فحص متصفح (Playwright) لكل الدروس الـ31 على 1440/1180/820/390 بكسل: لا خروج للمحتوى عن الشاشة ولا أخطاء في الكونسول، وكل المختبرات، وتدفق الامتحان، والنسخة المستقلة عبر `file://`.
